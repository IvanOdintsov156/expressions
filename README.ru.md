# Expressions: Отслеживание Эмоций и ИИ-Ассистент

Expressions — это мобильное приложение, разработанное для помощи пользователям в исследовании, понимании и размышлении над своими эмоциями. Оно сочетает технологию распознавания эмоций на лице с чат-ассистентом на базе ИИ, чтобы предоставить уникальный и личный опыт для эмоционального благополучия.

Ключевые особенности включают:
- Анализ эмоций по фотографиям, сделанным камерой или загруженным из галереи.
- Взаимодействие с ИИ-эмоциональным ассистентом, который учитывает ваши недавние эмоциональные состояния.
- Отслеживание вашей эмоциональной истории и получение инсайтов (функция в разработке).
- Безопасная аутентификация пользователя и конфиденциальность данных.
- Настраиваемая тема приложения (светлая/темная).

## Возможности

-   **Распознавание Эмоций на Лице**:
    -   Снимайте фотографии непосредственно через интерфейс камеры приложения.
    -   Загружайте существующие изображения из галереи вашего устройства.
    -   Использует модель машинного обучения для анализа выражений лица и определения основных эмоций (например, счастье, грусть, гнев, удивление).
    -   Отображает оценки уверенности для обнаруженных эмоций.
-   **ИИ-Эмоциональный АссистенENT**:
    -   Ведите текстовые беседы с интеллектуальным ИИ-ассистентом.
    -   Ассистент может помочь вам исследовать ваши чувства, предложить поддерживающие ответы и предоставить пространство для размышлений.
    -   Он учитывает ваши недавно проанализированные эмоции по фотографиям, чтобы предложить более персонализированное взаимодействие.
-   **Аутентификация Пользователя**:
    -   Безопасное создание учетной записи и вход с использованием email/пароля.
    -   Функции сброса и изменения пароля.
-   **История Эмоций и Инсайты (Планируется)**:
    -   Просматривайте историю ваших проанализированных эмоций с течением времени.
    -   Получайте инсайты о ваших эмоциональных паттернах и тенденциях (эта функция в настоящее время находится в разработке, и инсайты будут доступны через экран `StatsScreen`).
-   **Настройка Темы**:
    -   Персонализируйте свой опыт использования приложения с помощью светлой и темной тем.
-   **Кроссплатформенность**:
    -   Создано с помощью React Native и Expo, что обеспечивает совместимость с устройствами iOS и Android.

## Технологический Стек

-   **Фронтенд**:
    -   [React Native](https://reactnative.dev/): JavaScript-фреймворк для создания нативных мобильных приложений.
    -   [Expo](https://expo.dev/): Платформа и набор инструментов для разработки на React Native, упрощающие сборку и рабочие процессы разработки.
    -   [TypeScript](https://www.typescriptlang.org/): Типизированное надмножество JavaScript, повышающее качество и поддерживаемость кода.
    -   [React Navigation](https://reactnavigation.org/): Для маршрутизации и навигации внутри приложения.
    -   [React Native Paper](https://callstack.github.io/react-native-paper/): Библиотека UI-компонентов, реализующая Material Design.
-   **Бэкенд и Сервисы**:
    -   [Supabase](https://supabase.io/): Firebase-альтернатива с открытым исходным кодом для базы данных, аутентификации и хранения.
        -   *Supabase Auth*: Управляет аутентификацией пользователей (email/пароль, социальные входы, если реализованы).
        -   *Supabase Database*: Хранит данные пользователей, результаты анализа эмоций и историю чата.
    -   [Hugging Face Inference API](https://huggingface.co/inference-api): Используется для доступа к модели распознавания эмоций на лице.
    -   [ChatGPT API (через RapidAPI)](https://rapidapi.com/): Обеспечивает диалоговые возможности ИИ-эмоционального ассистента.
-   **Управление Состоянием**:
    -   React Context API: Для управления глобальным состоянием, таким как предпочтения темы.
-   **Стилизация**:
    -   Styled Components (через `globalStyles.ts` и стили конкретных компонентов).
    -   Expo Linear Gradient для градиентных эффектов.

## Настройка и Установка

Чтобы запустить Expressions на вашем локальном компьютере, выполните следующие шаги:

**1. Предварительные требования:**

*   **Node.js:** Убедитесь, что у вас установлен Node.js (рекомендуется LTS-версия). Вы можете скачать его с [nodejs.org](https://nodejs.org/).
*   **npm или Yarn:** npm поставляется вместе с Node.js. Yarn можно установить с [yarnpkg.com](https://classic.yarnpkg.com/en/docs/install).
*   **Expo CLI:** Установите Expo CLI глобально, выполнив команду:
    ```bash
    npm install -g expo-cli
    ```
    (или `yarn global add expo-cli`)
*   **Git:** Убедитесь, что Git установлен в вашей системе.

**2. Клонируйте Репозиторий:**

```bash
git clone https://github.com/your-username/expressions.git # Замените на актуальный URL репозитория
cd expressions
```

**3. Установите Зависимости:**

Установите зависимости проекта с помощью npm или yarn:

```bash
npm install
```

или

```bash
yarn install
```

**4. Переменные Окружения:**

Этот проект требует API-ключей и конфигурации для Supabase и ИИ-сервисов.

*   Создайте новый файл с именем `.env` в корне проекта.
*   Добавьте следующие переменные окружения в ваш файл `.env`, заменив значения-заполнители вашими актуальными ключами:

    ```env
    EXPO_PUBLIC_SUPABASE_URL=ВАШ_SUPABASE_URL
    EXPO_PUBLIC_SUPABASE_ANON_KEY=ВАШ_SUPABASE_ANON_KEY

    # Для Hugging Face Inference API (используется в endpointhf.tsx)
    # Возможно, вам потребуется настроить это непосредственно в коде или установить как переменную окружения,
    # если код будет рефакторен для ее использования. На данный момент, проверьте `endpointhf.tsx`.
    # Пример:
    # HUGGING_FACE_API_KEY=ВАШ_HUGGING_FACE_API_KEY
    # HUGGING_FACE_API_URL=ВАШ_HUGGING_FACE_INFERENCE_ENDPOINT_URL

    # Для ChatGPT API (через RapidAPI, используется в screens/AssistantChatScreen.tsx)
    # Обычно используются как заголовки в API-запросе.
    # Текущая реализация содержит их жестко закодированными.
    # Настоятельно рекомендуется перенести их в переменные окружения.
    # Пример:
    # RAPIDAPI_KEY=ВАШ_RAPIDAPI_KEY
    # RAPIDAPI_HOST=ВАШ_RAPIDAPI_HOST
    ```

    **Примечание по API-ключам:**
    *   **Supabase:** Получите ваш URL и Anon Key из настроек вашего проекта Supabase.
    *   **Hugging Face:** Файл `endpointhf.tsx`, похоже, напрямую использует токен. Для лучшей безопасности и конфигурируемости это следует перенести в переменную окружения. Текущая реализация использует `HF_TOKEN`. Вам следует создать этот токен в настройках вашей учетной записи Hugging Face.
    *   **ChatGPT (RapidAPI):** Файл `AssistantChatScreen.tsx` содержит жестко закодированные API-ключи. Это **не рекомендуется для производственного или совместно используемого кода**. Вам следует абстрагировать их в переменные окружения и загружать аналогичным образом.

**5. Запуск Приложения:**

*   **Запустите сервер разработки Expo:**
    ```bash
    expo start
    ```
*   Это откроет новую вкладку в вашем веб-браузере с Expo Developer Tools.
*   **Запуск на физическом устройстве:**
    *   Установите приложение "Expo Go" на ваше устройство iOS или Android.
    *   Отсканируйте QR-код, показанный в Expo Developer Tools или в вашем терминале, с помощью приложения Expo Go.
*   **Запуск на эмуляторе/симуляторе:**
    *   Убедитесь, что у вас установлены и настроены Android Studio (для эмулятора Android) или Xcode (для симулятора iOS).
    *   В Expo Developer Tools в вашем браузере нажмите "Run on Android device/emulator" или "Run on iOS simulator."
    *   В качестве альтернативы вы можете использовать следующие команды в вашем терминале:
        ```bash
        expo run:android
        ```
        ```bash
        expo run:ios
        ```
        (Эти команды могут потребовать дополнительной настройки, если вы ранее не создавали клиент разработки.)

## Руководство по Использованию

1.  **Регистрация / Вход:**
    *   При запуске приложения вам будет предложено создать новую учетную запись или войти с существующими учетными данными.
2.  **Главный Экран - Анализ Эмоций:**
    *   Перейдите на вкладку "Home" или "Analyze".
    *   Нажмите на **иконку камеры**, чтобы сделать новую фотографию.
    *   Нажмите на **иконку галереи**, чтобы выбрать существующую фотографию с вашего устройства.
    *   Для анализа можно выбрать до 5 изображений.
    *   Как только изображение отобразится, нажмите на **иконку отправки**, чтобы отправить его на анализ эмоций.
    *   Приложение отобразит обнаруженную эмоцию и оценку уверенности.
    *   Вы можете удалить загруженные фотографии с помощью **иконки удаления**.
3.  **Экран Чата с Ассистентом:**
    *   Перейдите на вкладку "Chat" или "Assistant".
    *   Здесь вы можете вводить сообщения ИИ-эмоциональному ассистенту.
    *   Ассистент ответит, учитывая результаты вашего недавнего анализа эмоций (если таковые имеются), чтобы обеспечить более релевантный разговор.
    *   Вы можете очистить историю чата с помощью иконки удаления в заголовке.
4.  **Профиль и Настройки:**
    *   Получите доступ к своему профилю для управления данными учетной записи, такими как изменение пароля.
    *   Переключайтесь между светлой и темной темами в разделе настроек или профиля.
5.  **Просмотр Статистики Эмоций (Экран Статистики):**
    *   Изучите вкладку "Stats", чтобы увидеть визуализации и сводки ваших записанных эмоций с течением времени (Примечание: этот раздел может все еще находиться в разработке).
